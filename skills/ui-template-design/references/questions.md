# 设计问题（最多 3 个，一次问完）

先从项目推断：已有 logo/品牌色、现有 CSS 变量、目标用户（内部工具/面向客户）。推断得出的不问。

| # | 问题 | 推荐答案 | 映射 |
|---|---|---|---|
| 1 | 主色调：沿用品牌色，还是中性灰 + 克制的蓝？ | 中性灰 + 蓝（工作台类） | `--accent-hue`、`--primary` |
| 2 | 气质：利落（小圆角）还是柔和（大圆角）？ | 利落 0.5rem | `--radius` 0.375–0.75 |
| 3 | 主按钮：深色中性还是品牌色？ | 深色中性（品牌色只做点缀） | `--primary neutral|accent` |

问法示例：

> 我会按「中性灰 + 克制的蓝、0.5rem 圆角、深色主按钮」生成主题（与常见工作台一致）。
> 需要改的话告诉我：①是否用品牌色 #xxxxxx 作为主色 ②圆角偏利落还是柔和 ③主按钮用不用品牌色。

不问：字体（固定 Geist + 中文系统字体）、密度（v4 仅 compact）、深色模式（总是提供）。
