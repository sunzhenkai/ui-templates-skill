# 来源:图片(image)

从截图、设计稿图片反推设计规范。核心思路:**整体风格靠看,色值靠取色,尺寸全部按估算处理**。

## 步骤

1. **保存原图**
   - 把图片复制到 `templates/<name>/assets/`,作为佐证材料,spec.md 中引用。

2. **整体风格判断**
   - 明暗、密度、圆角倾向、风格关键词——这些是图片最擅长传达的信息,放心归纳。

3. **取色**
   - 用工具提取主色板(如 `python` + `Pillow` 聚类,或 ImageMagick `convert -colors`),得到 dominant colors。
   - 再对照图像把色值映射到**角色**:面积最大的是背景,对比最强的小面积色是强调色,正文区取样得主文字色。
   - 聚类出的色值有偏差(抗锯齿、渐变会污染结果),标注 `(估算)`。

4. **字体与字号:估**
   - 字体族:能认出常见字体(Inter、SF、思源黑体等)就写"疑似 XX",认不出就按无衬线/衬线/等宽归类并给通用 fallback。
   - 字号阶梯:按视觉层级比例估(如正文约为页面标题的一半),标注 `(估算)`。
   - 如果知道原图的设计宽度(如 1440 设计稿),按比例推;不知道就说明基准不明,只给相对比例。

5. **间距、圆角、阴影:按档位估**
   - 不要假装精确。用档位描述:"圆角约 8px 档"、"卡片内边距约为字号的 1.5 倍"。

## 注意事项

- 几乎全部值都是估算,`confidence` 一般为 `medium`(风格清晰、取色可靠)或 `low`(图糊、元素少)。
- 单张图片信息有限:组件风格要点只能写图中实际出现的元素,没出现的写"来源未体现",不要脑补。
- 多张图(同一产品的多个页面)能显著提高置信度,主动向用户询问是否还有更多截图。
