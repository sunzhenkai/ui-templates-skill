# workbench-shell 设计规范

> 工作台/后台型 Web 应用的完整 App Shell 布局规范:整页不滚动、面板内部滚动,chrome 常量全局统一,1px 分割线分区,五种页面布局模式覆盖列表/主从/详情/设置/聚合网格。只约定布局与交互规则,不绑定技术栈;文中尺寸均为像素规格,实现方式自选。

- 来源:doc(用户提供的 Markdown 布局设计文档,原始项目出处已按要求抹除,业务实体已全部泛化)
- 采集日期:2026-08-30
- 佐证截图:无(`coverage.visual_reference: false`;视觉值为模板默认值)
- 精确值:见 [tokens.yaml](tokens.yaml)——颜色/字体为 `origin: default`,字号/间距/圆角来自来源
- 布局模式与组件契约:见 [routes-and-layouts.md](routes-and-layouts.md) 与 [components.md](components.md)
- 实施顺序与验收:见 [apply/playbook.md](apply/playbook.md);设计规则冲突时以本文件为准

## 0. 不可协商规则(Non-negotiables)

1. 根容器锁定 `100svh` 且 `overflow: hidden`,整页永不滚动;滚动只发生在内容列、列表、详情或看板列内部。
2. PageHeader 与 Toolbar 高度固定 48px,全应用一致;切换页面时标题位置不动。
3. 页左边距 GUTTER = 16px,页头、工具栏、正文行三条左线对齐。
4. 文档流内分隔只用 1px border,禁止阴影;阴影仅限 menu/dialog/popover/drawer/toast 浮层。
5. 字号只允许 `tokens.yaml` 的九档;禁止第十档或散落自定义。
6. 文字灰度只允许三级(`foreground` / `muted-foreground` / `faint-foreground`);禁止第四级。
7. 颜色、字体、间距、圆角、阴影必须映射自 `tokens.yaml`;新增值须在 Implementation Brief 显式批准。
8. `brand` 只用于未读点、激活态、主按钮、进行中状态;保持面积克制。
9. 双主题 token 名不变,暗色弱化方向反转,`light` / `dark` 角色键一致。
10. 跨页面导航使用真实 `<a href>`;当前项 `aria-current="page"`;可恢复状态进入 URL。
11. 平台路径(web/mobile/desktop)与窗口宽度解耦;web `<1024` 只从常驻浮岛切到覆盖抽屉,不变平台。
12. 覆盖抽屉内的路由跳转完成后必须自动关闭。
13. 每个页面映射到五种模式 A–E 之一,并按 [routes-and-layouts.md](routes-and-layouts.md) 的矩阵验收。
14. 主从双栏 compact 降级为单栏时,选中保留在 URL,返回列表后原选中仍高亮。
15. 骨架屏形状 = 最终布局形状;禁止无结构 spinner。
16. icon-only 控件 accessible name 非空;焦点可见;交互控件不得嵌套。
17. FAB 常驻;底部横栏、滚动内容与居中浮层为其让位。
18. 可拖宽面板内部样式用容器查询,不用窗口断点。

## 1. 整体风格

- 风格关键词:工作台、紧凑高密度、分割线分区、状态即 URL、双主题同构
- 明暗:双主题(亮暗同构,暗色下"弱化"方向反转,token 名不变)
- 密度:紧凑(导航行 28–32px,chrome 48px)
- 圆角倾向:柔和(画布卡片 14px,控件基准 10px,卡片 8px)

## 2. 配色

来源未体现具体色值;当前色值见 [`tokens.yaml`](tokens.yaml),全部为 `origin: default` 的模板默认值(双主题角色键一致,已做对比度预检)。角色语义与使用规则如下:

| 角色 | token | 说明 |
| --- | --- | --- |
| 页面背景 / 主文字 | `background` / `foreground` | 页面底 / 正文 |
| 导航底 / 导航悬停与激活底 | `sidebar` + `sidebar-accent`(+fg) | 应用底色 = 侧栏底色 |
| 弱底 / 次要文字 | `muted` / `muted-foreground` | 代码块、徽章底 / 次要文字 |
| 第三级弱化 | `faint-foreground` | 占位图标、禁用、装饰;文字灰度只有三级,不引入第四级 |
| 面板底 / 悬停 / 选中 | `surface` / `surface-hover` / `surface-selected` | 底色分层表达层级:导航底 < 导航悬停底 < 页面底 < 选中底 |
| 边框/分割线 | `border` / `surface-border` | 全局分割线 / 面板内分割线,1px |
| 主色(primary/brand) | `brand`(+fg) | 品牌强调,**只用于**:未读点、激活态、主按钮、进行中状态 |
| 状态色 | 状态色 tint | 看板列底等大面积低饱和着色(取状态色 5–8% 透明度) |

成功/警告/错误:具体值见 [`tokens.yaml`](tokens.yaml)(`origin: default`);空态/错误态图标的语气色分弱化/警示/危险三档(见 4.2)。

分区规则:文档流内一律只用 1px 边框,不用阴影;阴影只留给浮层(菜单/弹窗/悬浮卡,中等投影 + 1px 边框)。

## 3. 字体

- 字号阶梯:**唯一允许的九档**,禁止散落自定义:

| token | px/行高 | 用途 |
| --- | --- | --- |
| micro | 11/15 | 置顶计数、编号、键帽 |
| caption | 12/16 | 次要信息、未读数、组标题、时间戳 |
| label | 13/18 | 表单标签、按钮小字 |
| body | 14/20 | **默认正文**、页头标题、列表行 |
| body-lg | 15/22 | 强调正文 |
| title-sm | 16/24 | 卡片标题、小节标题 |
| title | 18/28 | 页面主标题(详情页 H1) |
| title-lg | 20/28 | 大标题 |
| display-sm | 24/32 | 落地/空态大字 |

- 字重用法:页头标题 14px 中等(medium);正文常规;来源未体现更多字重规则。
- 文字三级灰度:正文前景色 → 次要文字 → 弱化文字(占位/禁用/装饰图标),不引入第四级。

## 4. 间距与布局

- 间距基调:4 的倍数体系;页左边距 GUTTER = 16px(页头、工具栏、正文行共用,保证三条线左对齐)。
- 页面容器:根容器锁定视口高度 `100svh`,`overflow: hidden`,整页永不出现滚动条,一切滚动发生在内容列/列表面板内部。
- 密度基准:

| 项 | 值 |
| --- | --- |
| 页头/工具栏 | 48px |
| 侧栏导航行 | 高 28–32px,左内边距 8px,图标 16px,图标与文字间距 8px,行间距 2px |
| 列表行(内容区) | 内边距 8–10px 上下,行间 4px |
| 卡片内边距 | 12px;圆角 8px |
| 控件圆角基准 | 10px,派生小号 = 0.6×/0.8×/1×/1.4× |
| 图标 | 标准 16px;列表小图标 14px;空态大图标 40–48px |
| 头像 | 行内 20px;菜单/详情 32–40px |

详细布局规则见第 8 节起的各区域规范。

## 5. 组件风格要点

- 页头:高 48px + 下边框,flex 垂直居中,列间距 8px,`flex-shrink: 0`;三种形态(集合/面包屑/简单),见第 10 节。
- 卡片:白底(面板底)、8px 圆角、内边距 12px;悬停轻微底色变化,不用阴影。
- 看板列:列底色为状态色 5–8% 透明度 tint;列头 = 状态图标 + 名称 + 计数 + `…` + `+`。
- 范围切换:胶囊组(圆角小按钮)。
- 导航行:整行底色表达激活/悬停(激活 = 导航悬停底 + 文字转前景色,悬停更浅一档),不用左侧色条。
- 未读徽章:行尾右对齐 12px 数字,上限截断(如 99+)。
- 浮层(菜单/弹窗/悬浮卡):中等投影 + 1px 边框;文档流内只用边框。
- 骨架屏:形状 = 最终布局形状(等高行/标题条+段落条),禁止转圈。
- 空态/错误态/404:统一居中结构,见 10.2。

## 6. 其他特征

- 阴影:文档流内无;浮层中等投影 + 1px 边框;画布卡片极弱投影。
- 动效:

| 场景 | 规格 |
| --- | --- |
| 右栏/面板展开收起 | ≈220ms 弹性(spring stiffness≈420 damping≈38),位移 12px + 淡入 |
| 折叠箭头 | 200ms 旋转 90° |
| 路由切换 | 顶部 2px 进度条,不做页面转场 |
| 拖拽排序 | 拖起项降透明至 30%,释放回弹 |
| 数字徽章变化 | 可做短数字滚动,不复算动画 |

- 图标风格:来源未体现线性/面性约定;规则是"图标即语义,一处定义"——导航图标由目标路由派生而非逐项声明,保证侧栏、页签、面包屑等任何引用同一目的地的地方图标永远一致。
- 滚动渐隐:侧栏/长列表顶部用渐变遮罩提示"上方还有内容",遮罩高度 ≈24px。

## 7. 还原要点

照这几条做,页面就有这个风格的味道:

1. **应用不滚动,面板滚动**:根 `100svh` + `overflow: hidden`,滚动只发生在内容列内部;侧栏、页头、工具栏任何滚动位置都稳定可见。
2. **chrome 常量统一,页面不得自写**:页左边距 16、页头 48、工具栏 48 是全局常量;切换页签时标题移动 4px 就是 bug。
3. **用 1px 分割线分区,不用阴影**;底色分层表达层级,文字只有三级灰度,品牌色只给未读点/激活态/主按钮/进行中状态。
4. **状态即 URL**:选中项、页签、视图都进 query 参数,可深链、刷新还原。
5. **先铺底再放卡**:应用底色 = 侧栏底色铺满视口,内容区是圆角 14px 画布卡片,四周 8px 发丝缝。

## 8. 核心原则

1. **应用不滚动,面板滚动**。根容器锁定视口高度(`100svh`),整页永不出现滚动条;
   一切滚动发生在"内容列/列表面板"内部。这让侧栏、页头、工具栏在任何滚动位置都稳定可见。
2. **chrome 常量统一,页面不得自写**。页左边距、页头高度、工具栏高度是全局常量,
   由所有页面共用。页面各写各的间距是布局漂移的根源——切换页签时标题移动 4px 就是 bug。
3. **用分割线分区,不用阴影**。区域之间以 1px 边框分隔;阴影只留给浮层
   (菜单/弹窗/悬浮卡)。底色分层表达层级:导航底 < 导航悬停底 < 页面底 < 选中底。
4. **状态即 URL**。列表选中项、页签、视图都用 query 参数表达(如 `?id=`、`?tab=`),
   可深链、刷新后还原、可从通知直达。
5. **宽度可拖拽的都要记住尺寸**,且列表面板按**像素**记忆(不随窗口缩放),
   详情面板按比例记忆。
6. **文字三级灰度**:正文前景色 → 次要文字 → 弱化文字(占位/禁用/装饰图标),
   不引入第四级。品牌强调色只用于:未读点、激活态、主按钮、进行中状态。
7. **右下角常驻一个全局悬浮入口**(如 AI 助手对话球)。凡是从左侧或底部伸到右下角的元素
   必须为它让位(右/下内边距),居中悬浮元素改为抬高它的 bottom。
8. **图标即语义,一处定义**。导航图标由"目标路由"派生而非逐项声明,保证侧栏、
   页签、面包屑等任何引用同一目的地的地方图标永远一致。

## 9. 全局骨架(App Shell)与平台路径

### 9.1 平台路径(web / mobile / desktop)

实现时先按**平台路径**决定外壳,再按**断点**(768/1024,见第 13 节)决定画布内布局降级。
两者正交:桌面窗口缩到 <1024 时外壳不变,只有画布内按 compact 降级;不要把窗口宽度
当作平台判据。

| 路径 | 运行形态 | 侧栏 | 顶行(48px chrome) | 导航入口 |
| --- | --- | --- | --- | --- |
| **web** | 桌面/平板浏览器 | 浮岛(四周 8px 内缩,inset 变体),常驻可拖宽;<1024 自动折叠 | 无,画布顶到 8px 呼吸边 | <1024 页头左槽触发器 |
| **mobile** | 移动浏览器 / 移动壳 | 无浮岛,整体为覆盖式抽屉,路由跳转后自动关闭 | 无 | 页头左槽触发器;钻取页换返回钮 |
| **desktop** | 桌面客户端(Electron/Tauri 类) | 贴左缘,不内缩,常驻可拖宽 | 有:窗口控件浮层 + 浏览器式页签条 | 顶行内的侧栏开关 + 前进/后退 |

- 三条路径的**画布内页面层完全一致**(页头体系、五种模式、token 全部共用),差异只在外壳。
- 各路径外壳的详细规格:[platforms/web.md](platforms/web.md)、
  [platforms/mobile.md](platforms/mobile.md)、[platforms/desktop.md](platforms/desktop.md)。
- mobile 路径下呼吸边与浮岛不适用,画布卡片全幅铺到屏幕边缘(来源未明确,推算)。
- FAB、全局搜索、快捷键在三路径均常驻;desktop 的全局 overlay 仍挂画布卡片内,不盖侧栏。

### 9.2 骨架结构

先铺底,再放卡:**应用底色 = 侧栏底色**,铺满整个视口;内容区是一张
**圆角画布卡片**(圆角 14px + 1px 描边 + 极弱投影),四周留 8px 发丝缝浮在底色上;
侧栏和顶行 chrome 直接画在底色上。整页无滚动。

```
┌─ 应用底色(=侧栏底色),四周 8px 呼吸边 ─────────────────────────────┐
│ ┌─────────┐ ╔═内容画布卡片(rounded 14px, 8px 缝)════════════════╗ │
│ │ Sidebar │ ║ [顶行 h=48:窗口控件/页签条,仅桌面壳;web 无此行]      ║ │
│ │ 浮岛     │ ╟───────────────────────────────────────────────╢ │
│ │ w≈240   │ ║ PageHeader (h=48, border-b)                     ║ │
│ │ 200~360 │ ╟───────────────────────────────────────────────╢ │
│ │         │ ║ Toolbar (h=48, 可选)                             ║ │
│ │ (web:   │ ╟───────────────────────────────────────────────╢ │
│ │  四周8px│ ║              内容区(内部滚动)                     ║ │
│ │  内缩)   │ ║                                         [FAB]→ ║ │
│ └─────────┘ ╚═════════════════════════════════════════════════╝ │
└────────────────────────────────────────────────────────────────┘
```

- 根:`100svh`,`overflow: hidden`,横向 flex:侧栏容器 + 画布卡片。
- 外壳按平台路径渲染(定义见 9.1),画布内页面层完全一致;此处只留一行摘要,
  详细规格在各平台文件:
  - **web 壳**:无顶行;浮岛侧栏(四周 8px 内缩);画布顶到 8px 呼吸边。→ [platforms/web.md](platforms/web.md)
  - **mobile 壳**:无顶行;覆盖式抽屉侧栏;画布全幅(推算)。→ [platforms/mobile.md](platforms/mobile.md)
  - **desktop 壳**:48px 顶行(窗口控件浮层 + 浏览器式页签条);侧栏贴左缘不内缩。→ [platforms/desktop.md](platforms/desktop.md)
- **全局 overlay 全部挂在画布卡片内**(而非根上):模态注册表、全局搜索面板、
  右下角 FAB、顶部导航进度条(路由切换时顶边细进度条)、全局快捷键监听。
  好处:overlay 永远覆盖内容区而不会盖住侧栏。
- 路由守卫包在最外层:未认证/未选工作区时整壳替换为全屏居中的 loading(品牌图标)。

## 10. 页面 chrome(页头体系)

所有页面共用三个常量,任何页面**不得**自写:

| 常量 | 值 | 说明 |
| --- | --- | --- |
| 页左边距 GUTTER | 16px | 页头、工具栏、正文行共用,保证三条线左对齐 |
| 页头 PageHeader | 高 48px,下边框 | flex 垂直居中,列间距 8px,`flex-shrink: 0` |
| 工具栏 Toolbar | 高 48px,同 GUTTER | 紧贴页头下方,共同构成 96px 的 chrome 块 |

- **推右规则**:页头内容组用 `flex: 1` 占满把动作推到右侧,不在页头本身用
  `justify-between`(多槽时会将标题挤到中间)。
- **左槽**:页头最左是移动端导航触发器(<1024 显示;外层已有常驻触发器时不重复渲染);
  钻取型页面(如"列表 → 详情")可传入"返回"按钮替换它——返回优先级高于唤出导航。
- **标题截断**:标题 `truncate`(或 `min-width: 0` 链),右侧动作区 `flex-shrink: 0`。

### 10.1 三种页头形态

1. **集合页头**:`图标(16,弱化色) + 标题(14px 中等) + 计数(等宽数字,弱化) +
   描述(12px 弱化,≥768 才显示) + 右侧动作`。动作按钮响应式:窄屏只留图标
   (aria-label 兜底),宽屏图标+文字。
2. **面包屑页头**(详情页):`祖先链 › 祖先链 › 叶子 [动作]`。每个祖先 crumb 是
   **可点击链接**(指向其容器页);叶子不可点击;分隔符为 12px 弱化色右箭头。
   不可导航的占位(骨架/未知态)直接省略,不放不可点的假 crumb。
3. **简单页头**(列表页):`图标 + 标题`,或左侧标题 + 右侧新建动作。

### 10.2 统一空态/错误态(居中)

```
        ┌────────────┐
        │   ⌀ 48px   │  ← 圆底图标(色随语气:弱化/警示/危险)
        └────────────┘
            标题
   描述文字(最宽 448px,居中)
      [主按钮] [次按钮]
```

垂直内边距 64px,无边框无底色,动作横排居中。列表空、加载失败、404 共用此结构,
仅换 tone。

## 11. 左侧导航栏(Sidebar)

### 11.1 结构(自上而下)

导航项按业务替换,以下为泛化示例:

```
┌──────────────────┐
```

### 11.2 规格

| 项 | 规格 |
| --- | --- |
| 默认宽度 | 容器 256px(web 路径浮岛本体 240px,四周 8px 内缩;desktop 路径贴左缘不内缩);可拖拽 200–360,持久化;图标折叠态 48px;mobile 路径为覆盖式抽屉,路由跳转后自动关闭 |
| 头部 | 内边距 12px 上下;切换器行高 = 标准行高,头像 20px |
| 导航行 | 高 28–32px(紧凑),左内边距 8px,图标 16px,图标与文字间距 8px,行间距 2px |
| 组标题 | 11–12px 弱化色,上边距 16px,不可点击(可折叠组除外:整行可点 + 旋转箭头) |
| 未读徽章 | 行尾右对齐数字,12px;上限截断(如 99+);当前正在阅读的会话不计入 |
| 激活态 | 整行底色换成"导航悬停底",文字转前景色;悬停(非激活)用更浅一档底色 |

### 11.3 导航行为规则

- **激活匹配 = 前缀匹配**:`path === href || path.startsWith(href + "/")`,
  顶级项在其子页面保持高亮;置顶项例外,用严格相等(置顶的项目不应在自己子页仍亮)。
- 置顶项激活时,压制同路由的常规导航项高亮,避免两行同时亮。
- 未读计数来源分两类:行内数字 = 本空间各入口未读;切换器上的品牌点 =
  **其他**空间的未读或待处理邀请(本空间未读已由收件箱行表达,不重复计)。
- 列表加载中渲染等高骨架行(图标块 + 文字条),高度不变跳;数据已删除的置顶行
  静默隐藏,等用户手动清理或级联生效。

## 12. 五种页面布局模式

所有模式的外层一致:`flex:1; min-height:0` 的纵向 flex,先 chrome 后内容。
以下"条目/集合"泛指业务实体,可按业务替换。

### 模式 A · 单列工作列表页(看板/表格/列表多视图)

```
┌ PageHeader: 图标+标题 ────────────────────────────┐
┌ Toolbar: [范围胶囊 全部|我负责|我创建]  [状态摘要][筛选][显示][视图切换] ┐
├──────────────────────────────────────────────────┤
│ 内容表面(内部滚动):看板 | 表格 | 列表 | 泳道        │
└──────────────────────────────────────────────────┘
```

- 范围切换用**胶囊组**(圆角小按钮);右侧动作区从左到右:动态状态摘要
  (如"N 项进行中") → 筛选 → 显示选项 → 视图切换。
- 看板视图:横向滚动列;列头 = 状态图标 + 名称 + 计数 + `…` + `+`;
  列底色为状态色的极浅 tint,卡片白底圆角(8px)、内边距 12px;
  卡片内容:编号(11px 等宽) + 标题(2 行截断) + 描述单行截断 + 底部
  负责人头像 + 相对时间。支持列内/跨列拖拽。

### 模式 B · 主从双栏页(收件箱/对话类)

```
┌────────────┬─┬──────────────────────────────┐
│ 列表面板     ║ │ 详情面板                      │
│ PageHeader ║ │ (无页头时自有会话头)            │
│ ─────────── │ │                              │
│ 滚动列表    ║ │ 滚动内容                       │
│ 行=p-2     ║ │                              │
│ 间距=4px   ║ │ [固定底栏:输入区/横幅]           │
└────────────┴─┴──────────────────────────────┘
  320px (240~480)  可拖  ≥40%
```

- 外层为可拖拽分栏容器(横向);列表面板默认 **320px**,min 240 / max 480,
  按**像素**记忆;详情面板 min 40%。
- 列表面板:`border-r` + 内部自己的 48px 页头(标题 + 面板级动作) +
  `flex:1; min-height:0; overflow-y:auto` 的行列表(行内边距 8px,行间 4px)。
- 详情面板内容自上而下:会话头 → 滚动主体 → **状态横幅(粘性,位于输入区上方)**
  → 队列区 → 固定输入区。横幅只显示最高优先级的一条,优先级栈按业务定义
  (示例:权限吊销 > 归档 > 离线)。
- 空态(未选中):详情面板整体居中 `大图标(40px,弱化) + 提示文字`,
  不渲染残缺的交互件。
- **紧凑降级(<1024)**:单栏二选一。列表态 = 页头 + 滚动列表;
  详情态 = 顶部 48px 返回条(← + 列表名) + 全屏详情。

### 模式 C · 详情页(文档型:标题 + 富内容 + 属性栏)

```
┌ BreadcrumbHeader: 空间 › 集合 › 条目-123   [动作] ┐
├──────────────────────────────┬───────────────┤
│ 滚动主列                       │ 属性栏          │
│  居中限宽 896px                │ w=320          │
│  px: 12→32(md) py: 24→32      │ border-l       │
│  标题(20px)                   │ p-4,分组:      │
│  描述(富文本)                  │  状态/负责人/   │
│  ─分隔线─                     │  优先级/日期    │
│  活动流(时间线)                │  订阅者…       │
└──────────────────────────────┴───────────────┘
```

- 主列 `flex:1; overflow-y:auto`,内层 `margin:0 auto; max-width:896px`,
  水平内边距 12px(→32px ≥768),垂直 24–32px。
- 属性栏:`border-l; width:320px; padding:16px`,字段组之间 20px 间距 +
  1px 分隔线;**<768 整栏隐藏**(属性改从内容区操作)。
- 可选增强:属性栏做成可拖拽面板(默认 320 / min 260 / max 420),收起/展开带
  弹性动效(≈220ms spring,水平位移 12px + 透明度),并有快捷键;快捷键只作用于
  当前可见的详情页。
- 主列底部留出 FAB 安全区(原则 7)。

### 模式 D · 设置页(垂直页签)

```
┌──────────────┬───────────────────────────────┐
│ 帐户           │  内容列(min-width:0, flex:1, 滚动) │
│  个人资料      │   ┌───────────────┐            │
│  偏好          │   │ 限宽 768px     │            │
│  快捷键 …     │   │ (宽组件 1024)  │            │
│ 空间           │   └───────────────┘            │
│  一般 / 成员 … │                               │
│ w=224 p-4     │                               │
│ border-r      │                               │
└──────────────┴───────────────────────────────┘
```

- 桌面(≥768):左列 224px `border-r`,页签竖排、按"帐户级 / 空间级"分
  组标题;右列滚动,表单内容**限宽 768px**(个别宽组件放宽到 1024px)。
- 移动(<768):左列变为顶部横向可滚动的页签条(下边框),内容单列。
- 当前页签写入 URL(`?tab=`);书签旧值映射到新页签而非 404。

### 模式 E · 聚合网格页(卡片集合)

- chrome 用集合页头(10.1-1);内容为响应式卡片网格(自动填充,卡片 min ≈ 240px)。
- 每卡片:头部行(图标/头像 + 标题 + `…` 菜单)+ 两行摘要 + 底部元信息行
  (成员头像堆叠、计数、时间),白底 8px 圆角、悬停轻微底色变化。
- 空态走 10.2 统一空态,主 CTA 是"新建"。

## 13. 响应式规则

断点与平台路径(9.1)是两个正交维度:**平台路径决定外壳家族**(web 浮岛、mobile
全幅、desktop 顶行+贴缘侧栏),**断点决定画布内布局降级**。不要把窗口宽度当作平台
判据。web 路径允许在窄视口下改变侧栏的展开方式,但仍是 web 浮岛外壳;desktop 路径
不因窗口变窄变成 web 或 mobile 外壳。

两个断点:**768**(mobile)与 **1024**(compact)。另注意桌面窗口常落在 1024–1280,
设计必须在 <1280 就可用,不要只为大屏设计。

| 能力 | ≥1280 | 1024–1279 | 768–1023(compact) | <768(mobile) |
| --- | --- | --- | --- | --- |
| web 侧栏 | 常驻可拖宽浮岛 | 常驻可拖宽浮岛 | 收起常驻体,页头触发器 + 覆盖抽屉 | 收起常驻体,页头触发器/返回钮 + 覆盖抽屉 |
| mobile 侧栏 | 覆盖抽屉 | 覆盖抽屉 | 覆盖抽屉 | 覆盖抽屉,路由跳转后自动关 |
| desktop 侧栏 | 贴缘常驻可拖宽 | 贴缘常驻可拖宽 | 贴缘常驻可拖宽,外壳不变 | 贴缘常驻可拖宽,外壳不变 |
| 页头左槽 | 不渲染触发器 | 渲染触发器 | 渲染触发器 | 渲染触发器/返回钮 |
| 主从双栏(模式 B) | 双栏 | 双栏 | **单栏切换** | 单栏切换 |
| 详情属性栏(模式 C) | 显示(可折叠) | 显示 | 隐藏 | 隐藏 |
| 设置页签(模式 D) | 垂直 | 垂直 | 横向条 | 横向条 |
| 页头动作 | 图标+文字 | 图标+文字 | 图标+文字 | 仅图标 |
| 页头描述 | 显示 | 显示 | 显示 | 隐藏 |

> 注:上表中"侧栏"三行描述平台外壳随视口的表现,其余行描述画布内布局降级。web 路径在
> <1024 时不再渲染常驻浮岛本体,而是用页头触发器唤起覆盖抽屉;这不是切换成 mobile 平台,
> 而是 web 浮岛外壳的窄视口形态。desktop 路径的顶行和贴缘侧栏不因窗口宽度改变。

补充规则:

- **面板内响应式优先于窗口响应式**:凡是用户能拖宽的面板(模式 B 详情列),
  其内部样式用**容器查询**驱动,不要用窗口断点——窗口宽不代表面板宽。
- 双栏在 compact 降级时,选中状态必须保留(URL 里),返回列表后原选中项仍高亮。
- 抽屉/弹层内触发路由跳转后必须自动关闭,否则用户会以为"点了没反应"。

## 14. 状态与交互约定

- **骨架屏形状 = 最终布局形状**:列表 → 等高行(图标块+文字条);详情 →
  标题条(75% 宽)+ 段落条;侧栏 → 等高导航行。禁止转圈替代结构骨架。
- **选中即 URL**(原则 4);URL 与内部 store 双向同步时,同步逻辑必须幂等,
  避免两个方向互相覆写造成深链失效。
- **一次性意图参数用后即删**:如 `?create-with=x` 表示"新建并绑定 x",消费成功或
  失败(无权限)都要从 URL 移除,且显式用户操作可随时作废未消费的意图。
- **横幅优先级栈**:同一位置可能出现的提示(权限/归档/离线…)只渲染最高优先级
  一条,固定于输入区/工具区上方,不随内容滚动。
- **右下角 FAB 让位**(原则 7):底部横栏预留右内边距、滚动内容预留底部内边距、
  居中悬浮件抬高 bottom;距离常量由 FAB 自身几何派生并全局命名复用。
- **快捷键**:全局(搜索、新建、切换右栏)注册在壳层;涉及输入框的快捷键在
  可编辑元素聚焦时失效;页头动作行尾展示键帽(仅装饰,pointer-events 关闭)。
- **滚动渐隐**:侧栏/长列表顶部用渐变遮罩提示"上方还有内容",遮罩高度 ≈24px。
- **滚动条稳定**:可滚动主列加 `scrollbar-gutter: stable`,避免出现/消失横跳。
