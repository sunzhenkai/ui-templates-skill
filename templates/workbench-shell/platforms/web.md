# workbench-shell · web 平台路径

> 运行形态:桌面/平板浏览器。共享规则(原则、token、chrome 常量、五种页面模式、断点降级)
> 见 [../spec.md](../spec.md),本文件只写 web 外壳的特有规格。

## 外壳

- 无顶行 chrome;侧栏是**浮岛**(inset 变体):本体 240px,四周 8px 内缩,容器宽 256px。
- 画布卡片上边缝由顶行位置补足——没有顶行时画布直接顶到 8px 呼吸边。
- 全局 overlay(模态、搜索面板、FAB、进度条、快捷键)挂在画布卡片内,不盖侧栏。

## 侧栏

- 常驻、可拖拽调宽 200–360px 并持久化;图标折叠态 48px。
- 视口 <1024 时自动折叠(可展开);此时导航入口是页头左槽触发器。

## 导航入口

- ≥1024:侧栏常驻,页头左槽不渲染触发器。
- <1024:页头最左渲染导航触发器;钻取型页面用"返回"按钮替换它(返回优先)。

## 断点行为

画布内布局降级按断点表(spec.md 第 13 节)执行,与外壳无关——浏览器窗口缩到 <1024
时浮岛外壳不变,只有画布内按 compact 降级。
