# routes-and-layouts

本文件只补充页面模式与响应规则；颜色、字号、间距、圆角与阴影以 [`tokens.yaml`](tokens.yaml) 为准，通用壳规则以 [`spec.md`](spec.md) 为准。

## 1. 壳层级

```text
root（100svh / overflow hidden）
└─ shell surface = app-shell
   ├─ 左侧导航
   └─ content canvas = page-canvas（overflow hidden）
      ├─ NavigationProgress（2px）
      ├─ 页面列（内部滚动）
      ├─ Modal registry
      └─ FloatingChat / FAB
```

- Web 与 Desktop 使用上述壳。页面不再自带根滚动；只有页面列、列表、看板列、详情或设置内容滚动。
- 全局搜索、通知桥、浮动聊天与 modal registry 属于壳级能力，但视觉覆盖范围在 content canvas 内。
- 未认证、工作区解析中或无权限时，整壳可替换为全屏 loading / 错误态；不得渲染半个侧栏。

## 2. 页面 chrome

| 槽位 | 几何 | 规则 |
| --- | --- | --- |
| PageHeader | 48px，底部 1px 边框 | 左侧 16px gutter；标题可截断；动作区 `flex-shrink: 0`。 |
| Toolbar | 48px，紧接页头 | 与 PageHeader 共用左线和 gutter；过滤、视图切换、排序与主动作放这里。 |
| 内容区 | `flex: 1`，`min-height: 0` | 只在自身轴滚动；底部浮层预留 64px。 |

页头形态：

1. **集合页头**：16px 弱化图标 + 14px medium 标题 + 等宽计数 + 12px 描述 + 右侧动作。描述在 `md` 以下隐藏。
2. **详情 / 面包屑页头**：祖先链可点击，叶子和骨架不可点击；分隔符为弱化右箭头。
3. **简单页头**：图标 + 标题；或标题在左、新建动作在右。

窄屏时 PageHeader 提供返回导航的触发器。Desktop 已在外层窗口工具栏保留触发器时，页头不得重复渲染。

## 3. 页面模式

| 模式 | 结构 | 适用 |
| --- | --- | --- |
| A. 常驻集合 | PageHeader + Toolbar + 全幅内容 | 列表网格、卡片网格、表格、看板、泳道。 |
| B. 主从 | 列表列 + 详情列，均有独立滚动 | 资产 / 消息 / 工单型详情；compact 降级为单列。 |
| C. 设置页签 | 224px 页签列 + 内容列 | 窄屏页签横排并整页滚动；`md+` 纵向页签、内容独立滚动。 |
| D. 聊天 / 时间线 | 会话列表 + 消息时间线 + 底部 composer | composer 固定底缘；时间线内部滚动。 |
| E. 聚合网格 | 响应式卡片 / 指标网格 | 卡片列数随容器而非窗口变化。 |

模式切换不得改变壳、PageHeader 或 Toolbar 几何。每个路由必须能归入 A–E 之一；新增混合模式先拆成可验收的槽位。

## 4. 响应与容器查询

- 左侧导航：`1024–1279px` 自动折叠；`<1024px` 用 288px 覆盖 Sheet；Desktop 的外层触发器优先。
- 集合工具栏动作：窄屏保留 icon-only + accessible name；`md+` 显示 icon + label。
- 设置页签：`<md` 横向滚动页签；`md+` 左侧 224px 纵向页签。
- 设置内容：默认最大 768px；属性 / 状态 / 快捷键等宽表面可到 1024px。
- 卡片聚合：基础 1 列，中等 2 列，桌面宽度 4 列；间距 12px。
- 列表网格：容器 `<@2xl` 只显示核心列；容器 `@2xl+` 显示所有启用列并横向滚动。列显隐必须始终可由用户解释，不得因宽度静默关闭。

## 5. URL 与状态

- 当前集合视图、看板 / 表格 / 列表模式、过滤、排序、选中项、详情、设置页签与 Desktop 页签必须可通过 URL 或等价路由状态恢复。
- 设置页签切换用 replace，不把每次临时页签切换写入浏览历史。
- 覆盖 Sheet / Drawer 内发生路由跳转后必须关闭。
- 空结果必须区分“没有数据”和“过滤后为空”：后者提供清除过滤动作。

## 6. 加载与状态

1. 列表骨架：4–6 条真实行高与圆角；列表网格保留真实表头。
2. 看板骨架：5 列、列标题、列宽和卡片形状；容器横向滚动。
3. 卡片骨架：图标位、标题、徽章和正文线按真实卡片排列。
4. 表格骨架画在真实 grid 内，避免列宽跳变。
5. 空态、错误态和 404 使用同一居中结构；错误用 `role="alert"`，加载 / 成功用 `role="status"`。
