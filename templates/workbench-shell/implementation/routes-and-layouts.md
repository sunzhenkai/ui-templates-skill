# workbench-shell · Routes, Layouts & Page Modes

本文定义 route inventory、五种页面模式、示例页面映射、响应式矩阵和 URL 状态约定。布局数值、chrome 高度、断点和视觉规则的权威来源是 [`../spec.md`](../spec.md)。

## 1. Route inventory 模板

每个消费项目都应先填这张表,再实现页面。

```text
| Route | 页面名 | 模板模式 | 业务域 | 主要动作 | URL params | 空态 | 错误态 | 权限 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
```

每个 route 必须回答:

1. 用户从哪里进入?
2. 页面完成什么任务?
3. URL 需要恢复哪些状态?
4. 没有数据时显示什么?
5. 请求失败时用户能做什么?
6. 无权限或实体不存在时显示什么?
7. 页面属于哪种 workbench 模式?

## 2. 五种页面模式

### 模式 A — 列表/集合页

用于事件列表、通知列表、规则列表、可筛选集合等。

#### 结构

```text
PageHeader 48px: 图标 + 标题 + 计数 + 描述 + 动作
Toolbar 48px:   搜索 / 筛选 / 排序 / 视图切换 / 主创建动作
Content:        内部滚动列表或表格
Footer/底部:    分页、批量操作或状态摘要
```

#### 必须实现

- 48px PageHeader 与 48px Toolbar 共用 16px 页左距。
- 列表滚动只发生在内容区,不推动页头或工具栏。
- 表格头、行 hover、selected、empty、loading skeleton、error retry。
- 筛选和排序写入 URL,或明确说明只保留在临时状态。
- 分页/游标状态写入 URL;页码变化不丢失其他筛选。
- 批量操作必须键盘可达,选择与打开行不嵌套。
- 行内动作不使用暗示外部打开的图标,除非真的打开外部资源。

#### 验收

- 改变筛选、排序、页码后刷新,列表结果可恢复。
- 空结果解释原因并提供下一步。
- 请求失败保留筛选条件并提供 retry。
- compact/mobile 下表格提供降级:横向滚动、列优先级、卡片化或行展开。

### 模式 B — 主从双栏页

用于收件箱 + 详情、消息列表 + 会话、工单列表 + 工单详情。

#### 结构

```text
List column:     默认 320px,min 240px,max 480px,可拖宽并按像素记忆
Detail column:   flex:1,最小 40%
List header:     48px
Detail:          会话头 / 滚动主体 / 状态横幅 / 固定输入区
```

#### 必须实现

- 选中项写入 URL。
- 刷新后原选中项仍高亮并恢复详情。
- compact(<1024)切换为单栏二选一。
- 详情态使用 48px 返回条;返回列表后原选中仍高亮。
- 状态横幅固定在输入区上方,只显示最高优先级一条。
- 无选中时详情面板显示居中空态,不渲染残缺交互件。

#### 验收

- 拖宽列表后刷新,宽度恢复。
- 选择第 N 项、刷新、返回列表,选中态仍正确。
- compact 下从列表进入详情再返回,焦点和滚动位置可用。
- 新消息、错误横幅和输入区不互相推挤。

### 模式 C — 文档详情页

用于事件详情、服务详情、变更详情、长文档型实体。

#### 结构

```text
Breadcrumb header: 空间 › 集合 › 条目-123 [动作]
Main column:       flex:1,内部滚动,内层 max-width 896px 居中
Property column:   320px,border-left,padding 16px
```

#### 必须实现

- 面包屑祖先使用真实 `<a href>`。
- 面包屑叶子是当前实体文本,不渲染为可点击控件。
- 面包屑页保留明确的页面标题语义。
- 主列底部为 FAB 预留安全区。
- 属性栏 <768 整栏隐藏,属性操作移入内容区。
- 实体不存在时显示 404/未找到空态,而不是空白主列。

#### 验收

- 点击祖先 crumb 导航到容器页,AX tree 中它是 link。
- 刷新详情 URL 后内容、状态和相关操作恢复。
- 无权限时显示解释和可用动作,不渲染假表单。
- 窄屏下属性字段仍可读、可编辑或提供替代入口。

### 模式 D — 设置页

用于工作区设置、成员权限、团队、通知规则、集成、个人偏好。

#### 结构

```text
Desktop ≥768:
  Left nav:      224px,竖排页签,按“帐户级 / 空间级”分组
  Content:       flex:1,内部滚动,内容 max-width 768px

Mobile <768:
  Tabs:          顶部横向可滚动页签条,下边框
  Content:       单列
```

#### 必须实现

- 当前页签写入 `?tab=`。
- 旧页签值映射到新页签或显示可理解的 not found,不静默回到默认。
- 每个表单控件有关联 label。
- 保存中有禁用态;保存失败保留输入并提供重试。
- 未保存修改切换页签时提醒或明确说明自动保存策略。
- 危险操作使用确认框。

#### 验收

- 刷新非默认页签,页面恢复。
- 窄屏下每个页签有 accessible name,不能只显示无名图标。
- 校验错误可见且关联到字段。
- 成功、失败、保存中和未保存状态都有用户可见反馈。

### 模式 E — 聚合网格页

用于服务目录、交付分析、仪表卡片、集合卡片。

#### 结构

```text
PageHeader 48px: 图标 + 标题 + 计数 + 描述 + 创建/刷新动作
Content:        响应式卡片网格,卡片 min ≈240px,内部滚动
Cards:          头部行 + 摘要 + 元信息行;可选状态、负责人、团队、时间
```

#### 必须实现

- 网格在小屏退化为单列或双列,不产生意外横向滚动。
- 卡片 hover 使用底色变化,不使用文档流阴影。
- 卡片主要点击目标与次要菜单分离。
- 统计卡数字使用 tabular figures 和模板允许的字号。
- 图表容器必须有文本摘要、图例或表格替代,不能只靠颜色。
- 空态解释原因并提供创建/调整筛选动作。

#### 验收

- desktop、compact、mobile 下网格层级稳定。
- 卡片状态不只靠颜色。
- 数据为空和请求失败的表现不同。
- 图表在窄屏下仍可理解。

## 3. 示例页面映射

以下映射帮助理解模式,不把业务实体固化进模板。消费项目应按实际业务替换。

```text
| 示例页面             | 主模式 | 说明 |
| ---                  | --- | --- |
| 收件箱               | B      | 列表 + 详情;compact 单栏;批量操作可借用 A 的工具栏规则 |
| 事件列表             | A      | 筛选、排序、分页、表格;若进入实体详情则补 C |
| 事件看板             | A/E 变体 | 固定横向看板列;列内滚动,不推动整页;卡片可拖拽并提供替代操作 |
| 服务目录             | E      | 响应式服务卡片网格、状态、负责人和团队 |
| 值班日历             | E 变体 | 响应式日历/班次卡;窄屏提供列表替代 |
| 交付分析             | E      | 指标卡、趋势容器、分布和排行 |
| 工作区设置           | D      | 竖排分组页签;成员/团队/通知/集成/偏好 |
| 事件/服务详情        | C      | 面包屑、主列、属性栏、活动流 |
```

看板、日历、分析等复合页可以组合多个模式规则,但必须声明主模式,并且滚动归属仍遵守 App Shell 原则。

## 4. 响应式矩阵

平台路径与断点是两个维度。web 平台在窄视口下改变侧栏展开方式,但不变成 mobile 平台;desktop 平台外壳不因窗口宽度改变。

### 外壳矩阵

| 平台路径 | ≥1024 | 768–1023 | <768 |
| --- | --- | --- | --- |
| web | 常驻浮岛侧栏,可拖宽 | 常驻体收起;页头触发器 + 覆盖抽屉 | 常驻体收起;页头触发器/返回钮 + 覆盖抽屉 |
| mobile | 覆盖抽屉 | 覆盖抽屉 | 覆盖抽屉,路由后自动关闭 |
| desktop | 48px 顶行 + 贴缘侧栏 | 48px 顶行 + 贴缘侧栏 | 48px 顶行 + 贴缘侧栏 |

### 页面内容矩阵

| 能力 | ≥1280 | 1024–1279 | 768–1023 | <768 |
| --- | --- | --- | --- | --- |
| 模式 A 表格 | 完整列 | 完整列或优先列 | 优先列 / 横向滚动 / 卡片化 | 优先列 / 卡片化 |
| 模式 B 双栏 | 双栏 | 双栏 | 单栏二选一 | 单栏二选一 |
| 模式 C 属性栏 | 显示,可折叠 | 显示 | 隐藏 | 隐藏 |
| 模式 D 页签 | 竖排 | 竖排 | 横向条 | 横向条 |
| 模式 E 网格 | 多列 | 多列 | 1–2 列 | 单列 |
| 页头动作 | 图标+文字 | 图标+文字 | 图标+文字 | 仅图标,必须有 accessible name |
| 页头描述 | 显示 | 显示 | 显示 | 隐藏 |

### 窄屏验收

- 页头左槽有导航触发器;钻取页用返回钮替换。
- 覆盖抽屉内选择真实路由后自动关闭。
- FAB 不遮挡底部横栏、输入区或最后一个列表行。
- 看板/日历允许横向滚动时必须有滚动提示、键盘/菜单替代或列表切换。
- compact 与 mobile 下没有控件因 `hidden` 丢失 accessible name。

## 5. URL 状态契约

### 参数建议

| 参数 | 适用页面 | 示例 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `ws` / route prefix | 多工作区应用 | `?ws=apollo-prod` 或 `/ws/apollo-prod/...` | 上次或默认工作区 | 需要深链到指定工作区时进入 URL |
| `id` | B/C、搜索结果、列表详情 | `?id=i-1` | 无 | 选中或打开的实体;无效时进入 not found |
| `tab` | D | `?tab=members` | 第一个可见页签 | 旧值映射到新页签或显式提示 |
| `view` | 事件、看板、日历、分析 | `?view=table` | 模板默认视图 | 枚举白名单校验 |
| `q` | A/E 的搜索 | `?q=latency` | 空 | 与筛选一起恢复 |
| `status` / `severity` | A | 逗号分隔或多值 query | 全部 | 只接受已知枚举 |
| `page` / `cursor` | A | `?page=2` | 1 | 筛选变化时重置 |
| `sort` | A | `?sort=-createdAt` | 业务默认 | 字段+方向白名单 |
| 一次性意图 | 创建/邀请/跳转 | `?create-with=s-2` | 无 | 消费成功或失败后从 URL 删除 |

### 状态同步规则

1. URL 是可恢复状态的 source of truth;内部 store 从 URL 初始化。
2. 用户操作更新 store 后同步 URL;URL 外部变化(返回/前进/手工修改)也更新 store。
3. 同步必须幂等,避免两个方向互相覆写。
4. 枚举参数使用白名单;无效值映射到默认或 not found,不要保留半初始化 UI。
5. 敏感信息、超大列表选中集合和临时 hover 不进入 URL。

### 浏览器行为

| 动作 | 期望 |
| --- | --- |
| 刷新 | 页面、选中项、页签、视图、筛选恢复 |
| 前进/后退 | 内容、导航高亮和滚动状态一致 |
| 复制链接到新标签页 | 相同角色可见相同状态;无权限时显示说明 |
| 修改为无效参数 | 进入安全默认、映射值或明确 not found |
| 删除已选实体 | 详情或选中态进入 not found/empty,不保留残缺操作 |

### Route inventory 示例

```text
| Route | 页面名 | 模板模式 | URL params | 空态 | 错误态 |
| --- | --- | --- | --- | --- | --- |
| /inbox            | 收件箱     | B     | ?id=&filter=   | 没有通知       | 加载失败 + retry |
| /events           | 事件列表   | A     | ?q=&status=&severity=&page=&sort= | 暂无事件 | 加载失败 + retry |
| /events/:id       | 事件详情   | C     | path id        | not found      | 加载失败 + retry |
| /board            | 事件看板   | A/E   | ?view=board&id= | 看板为空       | 加载失败 + retry |
| /services         | 服务目录   | E     | ?q=&status=    | 暂无服务       | 加载失败 + retry |
| /oncall           | 值班日历   | E 变体 | ?view=&cursor= | 暂无值班       | 加载失败 + retry |
| /analytics        | 交付分析   | E     | ?range=        | 无数据         | 加载失败 + retry |
| /settings         | 工作区设置 | D     | ?tab=          | 无可配置项     | 加载失败 + retry |
```

具体路由结构由消费项目决定;上表只要求每个页面都能完成同类契约。
