# Structural template

## 0. 不可协商规则（Non-negotiables）

1. [NN-001] 所有正文必须具有可读对比度。
2. [LAYOUT-001] Shell 画布无根滚动。
3. [LAYOUT-002] Board 横向非换行且列不收缩。
4. [LAYOUT-003] 主从布局使用独立 block scroll owners。
5. [LAYOUT-004] Overlay 归属 region 而非错误 DOM parent。
6. [QUALITY-001] Dialog content 四向 padding 必须完整。
7. [QUALITY-002] Navigation link hover 使用背景且无 underline。
8. [QUALITY-003] Entity-row link hover 无 underline。
9. [QUALITY-004] Button-link hover 可以有 underline。
10. [QUALITY-005] Inline prose link hover 与 navigation 分离。

精确值见 [tokens.yaml](tokens.yaml)，结构关系见 [fidelity.yaml](fidelity.yaml)。
